# assets/

Marca de Quick Robot. Se copia al proyecto y se optimiza en el build; los originales no se modifican.

| Archivo | Qué es | Uso |
|---|---|---|
| `logo-cabeza.svg` | Cabeza de Q-404 (viewBox 120 × 104) | Header, footer, favicon, final del nombre gigante |
| `q404/q404-<colores>.webp` | Q-404 de cuerpo completo, 530 × 840, fondo transparente, 6 combinaciones | Sección Q-404, alberca, 404, imagen al compartir |
| `q404/q404-impresion.webp` | Q-404, 800 × 1200 | Sección "Imprimiendo" |
| `ideas/<id>.webp` | Fotos de las 7 ideas | "¿Qué se te antoja?" |
| `talleres/<pantalla>.webp` | Capturas del sistema, 2880 × 1800 (inicio, pieza, pedidos, producción, existencias, reportes), negocio de ejemplo «Eje Z» | Para talleres (`docs/25 §4`); se reemplazan cuando cambien las pantallas del sistema |

Combinaciones (`src/config/q404.ts`): morado-verde (la principal), morado-amarillo, azul-lima, naranja-turquesa, rosa-menta, amarillo-azul.
