Material de referencia. **No se modifica.** Ver `docs/02-referencias.md`.

- `mockups/aprende/aprende.html` (portada), `aprende-filamentos.html` (tema con tabla y filtros) y `aprende-pieza.html` (artículo para clientes) — maquetas de Aprende (2026-11-13). El buscador funciona con una lista fija; los recuadros amarillos son notas. Diferencias con la web en `docs/21 §11`.
