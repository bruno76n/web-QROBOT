# reference/

Material de referencia. **No se modifica.** Ver `docs/02-referencias.md`.

- `mockups/index.html`, `catalogo.html`, `producto.html`, `admin.html` — se abren directo en el navegador. Los productos de ejemplo se guardan en el navegador; el panel del mockup no pide contraseña.
- `seed-photos/<slug>-<n>.webp` — fotos provisionales de los productos de ejemplo (las de `q-404` son los renders finales).
- `hero/hero-escritorio.webp` (2400 × 1350) y `hero/hero-celular.webp` (1200 × 1600) — portada por defecto.
- `mockups/aprende/` — maquetas de Aprende, una por tipo de pantalla, con el contenido real (empieza por `index.html`). Se abren desde la carpeta del proyecto (leen el logo y Q-404 de `assets/`). Diferencias con la web en `docs/21 §11`; reglas de dispositivos en `docs/24`.
- `mockups/talleres/` — maquetas de Para talleres (principal, precios y descargar; empieza por `index.html`). Leen las capturas de `assets/talleres/`. Diferencias con la web en `docs/25 §14`.
- `mockups/_base.css` y `_base.js` — base compartida de las maquetas de Aprende y Para talleres: header, footer, botones, tablas, preguntas y la calculadora (lo mismo que la web tiene en `global.css` y en sus componentes compartidos).
