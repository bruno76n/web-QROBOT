faqs:
- q: ¿Es más fuerte que el PLA?
  a: Es más rígido (se dobla menos), pero aguanta menos golpes. Si la pieza se golpea, usa PETG.
- q: ¿Puedo usarlo con boquilla de latón?
  a: Para una prueba corta, sí. Con uso seguido la desgasta y la pieza empieza a salir con falta de material.

## Datos

| Dato | Valor |
|---|---|
| Boquilla | 210–240 °C, acero endurecido, 0.4 mm o más |
| Cama | 45–65 °C |
| Calor que aguanta | 55 °C |
| Golpes | 23.2 kJ/m² |
| Rigidez | 3950 MPa (PLA: 2750) |
| Secado | 55 °C · 8 h |
| Impresora | Abierta o cerrada |
| AMS | Sí (Bambu PLA-CF) |
| Velocidad máxima | 250 mm/s |
| Recocido | 55–60 °C · 6–12 h |

## Usos

Soportes, marcos, piezas que no deben doblarse, drones y modelos de radiocontrol de interior.

## No se recomienda para

Calor, exteriores, piezas que reciben golpes.
